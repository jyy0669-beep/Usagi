우사기 플로팅 펫 (Android)

기능
- 화면 위에 우사기 캐릭터를 띄움
- 손가락으로 드래그해서 위치 이동
- 살짝 들썩이는 반복 애니메이션
- 앱에서 띄우기/숨기기 가능

실행 방법
1. PC에 Android Studio를 설치하고 이 폴더를 엽니다.
2. Gradle 동기화가 끝나면 휴대폰을 USB로 연결하고 개발자 옵션/USB 디버깅을 켭니다.
3. Run 버튼으로 휴대폰에 설치합니다.
4. 앱을 열고 '우사기 띄우기'를 누릅니다.
5. 설정 화면에서 '다른 앱 위에 표시' 권한을 허용합니다.
6. 앱으로 돌아와 '우사기 띄우기'를 다시 누릅니다.
7. 숨길 때는 앱을 열고 '우사기 숨기기'를 누릅니다.

참고
- 이 프로젝트는 Android 앱 소스이며, 이 채팅에서 휴대폰 화면에 직접 설치할 수는 없습니다.
- Android 버전/제조사 설정에 따라 알림 권한이나 배터리 제한 설정이 추가로 필요할 수 있습니다.
- 현재 포함된 캐릭터는 첨부 이미지에서 배경을 자동 제거한 정지 이미지이며, 움직임은 살짝 들썩이는 효과입니다.
