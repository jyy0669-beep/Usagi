우사기 플로팅 펫 — 휴대폰에서 APK 빌드하기

이 프로젝트는 Android 오버레이 펫 앱의 소스 코드입니다.
휴대폰에 직접 설치 가능한 APK 파일은 GitHub Actions의 온라인 빌드로 만들 수 있습니다.
이 과정은 GitHub 계정과 저장소 생성이 필요하며, 빌드가 성공해야 APK가 생성됩니다.

휴대폰에서 진행하는 순서
1. GitHub 계정으로 로그인합니다.
2. 새 저장소(repository)를 만들고, 이 ZIP의 압축을 풀어 나온 파일들을 저장소에 업로드합니다.
   중요: ZIP 파일 자체를 한 파일로 올리는 게 아니라, 압축을 푼 폴더 안의 파일/폴더를 올려야 합니다.
3. 저장소의 Actions 탭을 엽니다.
4. "Build Usagi Pet APK" 워크플로를 선택하고 "Run workflow"를 누릅니다.
5. 빌드가 성공하면 해당 실행 결과 페이지 아래 Artifacts에서 "UsagiPet-debug-apk"를 다운로드합니다.
6. ZIP 아카이브를 열어 app-debug.apk를 추출한 뒤 설치합니다. Android에서 설치 권한을 요청하면 본인이 신뢰하는 파일인지 확인한 후 진행하세요.
7. 앱을 열고 "우사기 띄우기"를 누른 다음, "다른 앱 위에 표시" 권한을 허용하고 앱으로 돌아와 버튼을 다시 누릅니다.

기능/제한
- 다른 앱 위에 캐릭터를 표시하고 드래그할 수 있습니다.
- 현재 애니메이션은 가볍게 들썩이는 효과이며, 걷기/뛰기/졸기 등 전체 동작 애니메이션은 아직 구현되어 있지 않습니다.
- 실제 빌드 결과는 GitHub Actions에서 확인해야 하며, 성공을 보장할 수 없습니다.
- APK는 디버그 빌드이며 Play 스토어 배포용 서명 버전이 아닙니다.
- Android 버전과 기기 제조사 설정에 따라 알림/배터리 설정이 필요할 수 있습니다.
